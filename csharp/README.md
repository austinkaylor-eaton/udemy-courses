# C# Courses

C# Udemy courses will live here. Each course gets its own sub-folder containing a `.sln` file and one `.csproj` project per topic/section.

## Conventions

- Folder name: kebab-case slug matching the course title
- Each topic is a separate `.csproj` added to the course solution
- Run `dotnet build` and `dotnet test` from the course root
